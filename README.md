# Online Examination System

An Online Examination System built using **HTML, CSS, and JavaScript**.

## 📌 About the Project

This web-based application allows students to attend an online exam, answer multiple-choice questions, submit their answers, and view their results instantly.

## ✨ Features

* ⏱️ 5-minute countdown timer
* 📝 Multiple-choice questions
* ✅ Automatic answer checking
* 📊 Score calculation
* 📈 Percentage calculation
* 🎯 Pass/Fail status
* 🔒 Submit button disabled after submission
* 📱 Responsive design
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Online-Examination-System/

```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Select the answers.
5. Click **Submit Exam** to view your result.
